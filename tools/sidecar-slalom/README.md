# 边三轮绕桩实验室

独立、离线的中文绕桩模拟器。用浏览器直接打开同目录的 [index.html](index.html)，不需要安装依赖或启动服务。此工具不参与仓库原有电视应用的构建和打包。

分享或单独打开时，可生成内含样式与脚本的单文件版，避免只打开入口文件却缺少相邻资源：

```sh
node tools/sidecar-slalom/build-standalone.cjs artifacts/sidecar-slalom.html
```

生成后直接用浏览器打开输出 HTML 即可。画布在隐藏后重新展开、窗口尺寸改变或嵌入区域很小时会恢复重绘。

页面提供车辆与场地参数、三条轮迹、整车扫掠、车把和前轮角度、回放进度、全场/跟车视角、逐杆操作参照及 JSON 线路导出。点击逐杆表的一行，可定位到该杆附近全车净距最小的时刻。空格播放/暂停，左右方向键逐步查看；编辑输入框时不拦截按键。

“车辆几何”内还可修改主车前后悬、主车包络宽、边斗宽和前后端位置、车把枢轴位置以及轮胎尺寸。主车包络应包含脚踏、护杠和骑手占用；突出附件未计入就可能低估占地。三轮统一使用输入的保守轮胎矩形。边斗外形以边轮横向中心为对称中心；形状不对称的实车需要扩大包络。连接架用两根带半径的横向杆近似，其位置固定于模型，不能代表所有车型。

输入尺寸改变后，画面保留上次线路并明确标记“待重算”，旧线路不能播放或导出，需按“计算推荐线路”应用新参数。“恢复示例”同时恢复轮迹、扫掠和全场视角。参数保存在当前浏览器的本地存储中；文件地址不允许存储时仍可正常使用。导出的 JSON 明确区分 `feasible-candidate` 与 `diagnostic-only`，并带参数、搜索结果和采样轨迹。

前轮刚过杆时，后轮和边斗还没有全部过杆。不能看到前轮越过桩位就大幅回把，应结合整车扫掠以及边斗、把端的余量连续转向。这里的角度和位置是**跟随该条具体曲线的参照**，不是适用于其他车与场地的固定口诀。

## 模型与净距认证

### 三轮位置及车把

以后轮接地点为车体系原点，+x 向前，+y 向左；世界中场地沿 +X 前进。左转角为正。后轮路径为 y=f(x)：

```text
θ = atan(f')
κ = f'' / (1 + f'²)^(3/2)
δ = atan(L κ)
φ = δ / ratio
后轮点 = r
前轮点 = r + R(θ) (L, 0)
边轮点 = r + R(θ) (a, side × d)
车把端点 = r + R(θ) [ (handleX, 0) + R(φ) (0, ±handleWidth/2) ]
```

车把角 φ 与前轮角 δ 分开计算、显示。主车、边斗、三只轮胎采用定向矩形，车把与连接架采用胶囊体，净距检查使用这些实体的并集。轮迹只是轮中心的路径，不能替代整车碰撞检查。屏幕在投影阶段把 +y 反向到上方。

实时“瞬时定圆轮差”显示 `sqrt(R² + L²) − |R|`，其中 `R=1/κ`。它是在当前曲率保持不变时的前后轮圆轨迹半径差；变曲率绕桩的实际几何关系请看单独绘制的三条轮迹。

### 固定边轮的擦滑

模型假设主车前后轮无横向滑动，以自行车运动学推演后轮路径。对任一车身点 (x,y)，其车体系速度为：

```text
vpoint = v × (1 − κ y, κ x)
```

边轮前移 a>0 时，固定朝前的边轮必然有横向速度 `v κ a`，无法与主车前后轮同时纯滚动。“擦滑角”是 `atan2(κ a, 1−κ side d)`，表示这一运动学需求，**不是轮胎力或真实车辆稳定性的求解**。减速会降低横向擦滑速度，不能消除几何方向角。搜索还排除内侧边轮纵向速度可能为零或倒向的极端区域。

未建模轮胎刚度、实际前束、车架侧倾、悬挂、载荷、坡度、驱动/制动牵引、倾覆及路面附着。若要预测实际驾驶稳定性，需要实测车辆与动力学模型。

### 连续扫掠

桩杆按真实输入半径处理。用圆心到定向矩形/胶囊体的有符号距离减杆半径，得到杆净距；对四条边界检查各部件顶点/胶囊端点及半径。杆外圈是方便定位的放大标记，不参与碰撞检测。

最终候选会重新加密验证，不复用动画帧作安全判定。由曲线及引入段的解析导数全局上界，得到所有部件相对后轮纵向参数 x 的位移上界 B；车把和前轮额外计入自身转动。对最大采样间隔 Δx，最小采样净距再减 `B Δx/2`，给出连续轨迹的保守净距下界。默认目标扣减不超过 5 mm；资源限制下最多 200,000 个均匀区间，并仍按实际间隔扣减，不会把粗采样冒充精确值。

前轮峰值角使用曲率一阶导数上界扩张；转把速率使用其对 x 的导数上界扩张。引入/驶出采用五次平滑窗，路径是 C²，车把角连续，转把速率在接头处可有有限跳变；对接头左右极限额外取样。没有限制转把加速度或模拟转向系统惯性。所有通过判定仅针对这里的几何及运动学模型。

### 搜索范围与“最优”

后轮路线采用带平滑驶入/驶出的余弦与三次谐波族：

```text
y(x) = bias + first × amplitude × w(x)
       × [cos(t) + shape × cos(3t)] / (1 + shape)
t = π × (x − firstPoleX + phase) / spacing
```

在左右起绕侧、横向偏置、幅值、相位和形状上确定性网格搜索，再对多个优胜起点细化，最后独立加密验证若干候选。只包含共线等距杆、居中的矩形场地、后轮纵向单调前进的路线；不包含掉头、倒车、不等距杆或自由固定起终位置规划。入口/出口车头回正，其横向偏置随候选搜索；不是指定车道入口姿态的全局规划。

约束包括全车净距、前轮转角、转把速率、后轮依次在指定侧交替绕过桩杆及边轮不倒向。评分以最大化最窄净距为主，长度与转角作为很小的偏好项；得到的是**当前参数、已搜索曲线族中的最佳候选**，没有全局最优证明，也不保证最短距离。

## 验收

需要 Node.js 18+；浏览器集成检查另需已安装 Chrome，无需 npm 依赖。

```sh
node --test tools/sidecar-slalom/model.test.cjs
node tools/sidecar-slalom/browser-check.cjs
# 选择 Chrome 可执行文件：
CHROME_BIN=/path/to/chrome node tools/sidecar-slalom/browser-check.cjs
# 可选保存浏览器截图到被忽略的测试产物目录：
SIDECAR_SCREENSHOTS=test-artifacts/sidecar-slalom node tools/sidecar-slalom/browser-check.cjs
# 对单文件交付入口运行相同交互检查：
SIDECAR_PAGE=artifacts/sidecar-slalom.html node tools/sidecar-slalom/browser-check.cjs
```

数值测试覆盖恒曲率三轮轨迹、车把碰杆、矩形边角越线、部件空隙、解析导数与差分、部件速度界、整车镜像、减速影响、默认可行路线及更密采样复核、过窄场地和跳杆拒绝。浏览器检查覆盖直接文件打开、实际回放、进度定位、跟车视角、参数失效与旧轮迹保留、不可行提示、恢复示例、手机宽度、画布隐藏后恢复、极窄嵌入视图及未捕获异常。单文件入口还会检查没有外部脚本或样式依赖。
